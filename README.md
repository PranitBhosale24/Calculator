# Calculator
A command line calculator program developed using basic python

## Features
1) Addition
2) Subtraction
3) Multiplication
4) Division
5) Factorial
6) Modulus
7) Power
8) Square Root
9) Average
10) Percentage
11) View History
12) Clear History

## Concept Used
- Variables and Data Types
- If-else
- For and While Loops
- Try Except
- File Handling

## Technologies
- Python
- No external Library

## How to run
1. Make sure Python is installed
2. Download or clone this repository
3. Run the program
