# Calculator
A command line calculator program developed using basic python

## Features
1) Addition
2) Subtraction
3) Multiplication
4) Division
5) Factorial
6) Modulus
7) Power
8) Square Root
9) Average
10) Percentage
11) View History
12) Clear History

## Concept Used
- Variables and Data Types
- If-else
- For and While Loops
- Try Except
- File Handling

## Technologies
- Python
- No external Library

## How to run
1. Make sure Python is installed
2. Download or clone this repository
3. Run the program

## Flow of the program
1) Enter 1 for basic calculator , 2 for Scientific Calculator , 3 for History and 4 for Ending the program.
2) If choose 1 then in operation type '+' for Addition , '-' for Subtraction , '*' for Multiplication , '/' for division.
3) If '=' then it will give you your result and end the loop returning to the main menu.
4) If choose 2 then in operation type '!' for factorial , '%' for Modulus , '^' for Power , '>' for Square Root , '<' for Average and '?' for percentage.
5) In case of Average if you write a char value then it will give you an answer means when you give integer till then it will accept input when you give a char then it will stop taking the integer and give you your average value.
6) After Operation it will give you result and returns you to main menu.
7) If you choose 3 then you have 2 choice . 1 to see the history and 2 for clearing the history.
8) If you choose 4 in main menu it will end the program
